LIBS Lithium Comparison

Converts LIBS .tdms files to CSV in your browser, then measures the lithium lines in each sample, checks them for calcium overlap and detector saturation, and ranks the samples against one another. Files are read locally and never leave this page.

Drop .tdms files here (and a CSV of sample variables, if you have one), or choose them. Each file becomes one sample; every numeric channel in it (one per grid location) is treated as a replicate.

How much lithium is in each sample, relative to the others?

Concentration = (measured value − intercept) ÷ slope, for the measure selected above. Saved in this browser only.

Sample variables for the x-axis

Give each sample a value for whatever you varied: time, pH, salinity, depth, temperature. Type values in, or load a CSV whose first column is the sample (file) name and whose other columns are variables, one per column, with units in the header if you like, for example sample,time (h),pH,salinity (g/L). Values are remembered in this browser; the CSV is the way to share them.

The ceiling defaults to 16-bit (65,535 counts), which is an assumption about your spectrometer. Change it if your detector clips elsewhere. Spectra in these files are already averaged over the laser shots at each location, so a single saturated shot can hide below the ceiling: the check also flags peaks with flat tops (four or more pixels within 1% of the maximum).

Each line is measured as the highest pixel within the window, minus a baseline taken as the median of pixels 0.35 to 1.2 nm either side (pixels near other listed lines are left out). Noise is the robust scatter of those same baseline pixels. The Ca ratio is the theoretical value for these two lines, which share an upper level; once you have a lithium-free calcium standard, replace it with the ratio you measure.
